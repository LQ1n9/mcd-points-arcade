## 一、产品定位

麦门积分玩家是一个 **积分运营台**：把麦当劳会员散落在各处的积分资产（账户余额、即将过期的积分、积分抽奖、积分商城、卡包优惠券、每月活动）聚到一个台面，用真实数据帮你

- **体检**：积分余额、临期积分预警，别让积分睡大觉；
- **参谋**：奖池实时情报 + 商城「每元积分成本」性价比排序，告诉你哪样最值；
- **执行**：在你说"好"之后，真的帮你抽奖、真的帮你兑换、真的帮你一键领券。

它不是又一个"推荐吃什么"的小玩具，而是**直接操作你真实积分资产**的运营台——这就是它和 MCP 的强耦合。

## 三、趣味设计

六大专员，玩家化但不迷信：

1. **账户体检官** `account` —— 余额 / 临期预警，别浪费。
2. **奖池情报站** `lottery` —— 实时奖池、单次消耗、可抽次数。
3. **抽奖参谋 + 真抽** `draw` —— 基于真实余额的策略建议，**你确认后**真实抽奖，战绩入档案。
4. **商城淘金侠** `mall` / `redeem` —— 按"每元积分成本"给你排好序，**你确认后**真实兑换下单。
5. **卡券收纳师** `coupons` / `autobind` —— 盘点卡包、标临期券，**你确认后**一键领券。
6. **玩家等级 + 真实战报** `profile` / `report` —— 动作累计成等级，一键生成可分享战报。

> 合规边界：本作品**不提供任何算命 / 命运 / 天意类输出**，全部基于真实账户数据做策略与预警；不贬低品牌、不宣扬不健康饮食 / 拜金 / 娱乐至上。写操作一律 **consent-gated**，未获你明确确认绝不调用。

## 四、热门内容

积分、薅羊毛、卡券临期——都是高频生活痛点。每个人都想"把手里的积分用足、别浪费"，每个人跑出来的都是"我的真实战报"。这正是它自发传播的底。

## 快速开始

### A. 作为 WorkBuddy Skill（推荐，契合赛事加分项）

1. 在 WorkBuddy「连接器」中配置麦当劳 MCP：名称 `mcd-mcp`，`https://mcp.mcd.cn`，Bearer Token 鉴权（Token 在 `https://open.mcd.cn/mcp` 申请）。
2. 安装本仓库的 `SKILL.md` 到 `~/.workbuddy/skills/mcd-points-arcade/`。
3. 对话里说"查我的麦当劳积分战报"即可触发。

### B. 作为独立 Python 客户端（零依赖）

```bash
export MCD_MCP_TOKEN="你的Token"        # 从 https://open.mcd.cn/mcp 申请
python mcd_arcade.py report              # 生成真实积分战报
python mcd_arcade.py lottery             # 奖池情报
python mcd_arcade.py mall                # 商城性价比排序
python mcd_arcade.py coupons             # 卡券盘点（含临期预警）
python mcd_arcade.py draw --yes          # 真实抽奖（消耗真实积分，需 --yes 授权）
python mcd_arcade.py redeem --spu 6113 --yes   # 真实积分兑换（需 --yes 授权）
python mcd_arcade.py autobind --yes      # 一键领券（需 --yes 授权）
```

> 未配置 Token 时自动进入**演示模式**（数据清晰标注为演示，绝不冒充真实）；写操作在演示模式下只展示将要执行的动作，不消耗任何真实积分。
